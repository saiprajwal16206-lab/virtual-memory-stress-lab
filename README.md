# Virtual Memory Stress Lab

An educational project for exploring how high memory use can affect a computer’s RAM, virtual memory, and performance.

## Project goal

Learn about memory pressure by running controlled experiments and observing what happens to the system.

## Project status

In development.

## How to run

Instructions will be added once the project code is uploaded.

## Safety note

Memory stress tests can make a computer slow or unresponsive. Start with small experiments, save your work first, and stop the test if your computer struggles.
